project showcase

This project was a T-shirt order form, built using HTML and CSS. It involved creating a form where users could submit their information to order a T-shirt. Through this project, I honed my understanding of form handling in web development, especially focusing on how to validate user input to ensure the data is correctly formatted.

I learned how to apply regular expressions (regex) to enforce constraints on input fields, such as ensuring that the name field contains a minimum of two characters. Additionally, I practiced using modern form attributes for validation, ensuring a smooth user experience. The project was designed to meet strict standards for performance, requiring a perfect score in Lighthouse and clean, accessible code.

Throughout the development, I made extensive use of Chrome DevTools to test and debug my code. I also used Lighthouse to analyze the performance and accessibility of the form, ensuring it was both lightweight and efficient. This experience helped me optimize my CSS, keeping it minimal and targeted, which contributed to a more refined and polished final product.
